# 🌸 百合小说导航站

> **Yuri小说 · GL小说 · 正版阅读指引**

一个 **纯静态的书目索引 / 阅读指引站** —— 只收录公开可见的**书名 / 作者 / 出处**，然后**链接回原平台**阅读。

🌐 线上地址：**https://yuri-nav.pages.dev**

---

## ⚠️ 本站不提供什么

- 🚫 **不存储**任何小说正文
- 🚫 **不制作**任何电子书文件
- 🚫 **不提供**任何下载链接
- 🚫 **不提供**网盘地址
- 🚫 **不破解**任何付费内容

本站**只做书名索引与指路**。所有作品版权归原作者及原发布平台所有，请支持正版阅读。

## ⚠️ 维护提醒

1. 改完 `app.js` 必须 `node --check app.js` 验证语法
2. **每次改 `app.js` / `style.css` 后，把 `index.html` 里的 `?v=` 换成没用过的新值**
   （否则浏览器/CDN 缓存会让你看不到改动）
3. **`'use strict'` 下不能忘记声明变量** —— 曾经因为漏写 `let __visCache` 导致全站书目和分类消失
4. 数据用**分片**（单片 < 300KB），单文件 5MB 在弱网下会被截断
5. 保持「不托管正文、不提供下载」的定位
